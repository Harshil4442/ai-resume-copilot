# Courier Prime fixture font

These four unmodified font files, `OFL.txt` and `METADATA.pb` come from the official [Google Fonts repository](https://github.com/google/fonts/tree/7204f5a9b1e530633e00c67bd4954ceb7d8c2483/ofl/courierprime), pinned to commit `7204f5a9b1e530633e00c67bd4954ceb7d8c2483`. `provenance.json` records the exact immutable download URLs, byte lengths and SHA-256 digests.

The original copyright notice and SIL Open Font License 1.1 are retained verbatim in `OFL.txt`. These files have not been modified or renamed. They are fixture dependencies, not a separately sold font product. Preserve the license and copyright with any redistributed copy. Times New Roman is not redistributed here; the materializer accepts a separately supplied local copy only when its actual family matches the frozen recipe.

The regular font's SHA-256 is `72f793376f8e2841656bf21d77a5de010f2929bd6956a22ee848ad0c7eb978af`. Providing this file to the offline materializer enables the Courier Prime PDF cases without a font substitution. Its presence does not establish that the document worker has the font installed or that DOCX/TeX rendering has passed.
