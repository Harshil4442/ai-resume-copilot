End-to-end product workflow.

The user moves from account setup to resume parsing, job matching, grounded AI explanations, learning strategy, market trend analysis, and dashboard tracking.

1

Authenticate

User registers or logs in. JWT token is stored in browser and sent with protected API calls.

2

Build Profile

User adds optional career context such as target role, location, links, skills, education, and bio.

3

Upload Resume

PDF or DOCX is parsed into raw text, sections, contact info, skills, and experience years.

4

Run Job Match

Resume evidence is compared with the job description to produce score, gaps, and recruiter dimensions.

5

Ask AI

Stateless RAG builds temporary evidence chunks and answers grounded questions about the selected match.

6

Generate Learning

Match gaps are converted into learning priorities, projects, resume bullets, and interview talking points.

7

Analyze Market

Live job providers are searched to find repeated skills and compare them with resume evidence.

8

Track Dashboard

Dashboard summarizes profile health, resume quality, match performance, recurring gaps, and activity.

Explained functionalities.

Each module is designed to feed the next one, so the app behaves like a connected career intelligence system instead of isolated tools.

Resume Parsing

Converts uploaded files into structured career data.

  • Supports PDF and DOCX.
  • Extracts contact info, sections, skills, and experience.
  • Stores parsed data per authenticated user.

Job Matching

Compares resume evidence with job requirements.

  • Extracts JD skills.
  • Classifies full matches, partial matches, and true gaps.
  • Returns score, grade, dimensions, summary, and tips.

Ask AI

Answers questions about a specific resume and match.

  • Builds temporary evidence chunks.
  • Ranks context with TF-IDF and rule boosts.
  • Does not store chat, chunks, embeddings, or vector indexes.

Learning Strategy

Turns gaps into a practical improvement plan.

  • Uses selected match history.
  • Creates priorities, projects, resume bullets, and interview points.
  • Falls back to deterministic generation if LLM fails.

Market Analyzer

Reads external job demand and compares it with the resume.

  • Integrates TheirStack, Adzuna, and Jooble.
  • Uses Redis cache when configured.
  • Normalizes 132 skills across 14 categories.

Dashboard

Shows progress and system-level career signals.

  • Profile completeness and resume quality.
  • Match trends and best/latest/weakest match.
  • Recurring skill gaps and next actions.

Technical sub-workflows.

These are the highest-value internal flows to explain in interviews or project walkthroughs.

Stateless RAG

Question -> load resume and match -> build 15 evidence sources -> classify one of 7 intents -> rank context -> LLM JSON answer.

  • No server-side chat persistence.
  • No vector database required.
  • Uses deterministic retrieval before LLM generation.

Market Trends

Role query -> provider registry -> Redis check -> live job search -> dedupe -> skill extraction -> resume gap analysis.

  • Counts each skill once per job.
  • Maps aliases such as JS, Postgres, K8s, and RESTful APIs.
  • Generates project recommendations from high-priority gaps.

Deployment

GitHub push -> CI checks -> frontend build -> backend container -> Cloud Run -> Vercel frontend calls Cloud Run API.

  • Cloud Build and Docker support backend deploys.
  • Vercel hosts Next.js frontend.
  • Render PostgreSQL stores persistent data.
